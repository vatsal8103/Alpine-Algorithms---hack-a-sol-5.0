1. EXECUTIVE SUMMARY & PROBLEM SPECIFICATION
================================================================================
In road offenses, hit-and-run incidents, vehicle thefts, and traffic violations,
CCTV footage is often severely degraded due to motion blur, low sensor resolution,
adverse lighting, camera vibration, and compression artifacts. In such scenarios,
a vehicle's license plate is rarely legible in a single snapshot.

Investigators frequently possess only partial characters or faint visual attributes.
Conventional ALPR/ANPR systems fail because they either force a binary recognition
decision on a single frame, or utilize naive majority voting that hallucinates
characters to satisfy string schemas.

TRACE-X solves this through a multi-frame evidential consensus architecture:
1. Multi-Frame Evidential Fusion: Character predictions and posterior probabilities
   are extracted across candidate video frames, dynamically weighted by sharpness,
   plate area, and OCR confidence, aligned via weighted Needleman-Wunsch edit distance,
   and constrained by Indian registration positional grammar.
2. Zero Hallucination Guarantee: Unreadable characters below acceptance thresholds
   or with insufficient margin over runner-up characters are preserved as '?' and
   never invented.
3. Multi-Criteria Composite Ranking: Blends partial-plate positional scoring
   (with confusable character pair discount penalties) with body colour similarity
   and body-type probability distributions.
4. Fail-Safe Abstention: The system explicitly yields NO_CONFIDENT_MATCH with an
   explainable rationale whenever evidence is contradictory, below threshold,
   or absent from the vehicle registry.
5. Decision-Support Mandate: Output is strictly framed as decision-support guidance
   for human investigators, never as definitive judicial proof.

3. SYSTEM ARCHITECTURE & END-TO-END PIPELINE SPECIFICATION
================================================================================

TRACE-X operates as a deterministic, modular, 10-stage processing pipeline:

   [ Raw CCTV Video Clip (.mp4 / .avi) / Live RTSP Stream ]
                       |
                       v
   +-----------------------------------------------------+
   | 1. Video Ingestion & Frame Selection                |
   |    - Adaptive extraction at 5 FPS                   |
   |    - Laplacian variance sharpness calculation       |
   |    - Drop blurry frames (sharpness < 25.0)          |
   |    - Retain top-N sharpest candidate frames         |
   +-----------------------------------------------------+
                       |
                       v
   +-----------------------------------------------------+
   | 2. Vehicle Detection & Multi-Object Tracking        |
   |    - YOLOv8s pretrained detector (COCO vehicle cls) |
   |    - ByteTrack association for persistent track_ids |
   |    - Handles occlusion, trajectory smoothing        |
   +-----------------------------------------------------+
                       |
                       v
   +-----------------------------------------------------+
   | 3. License Plate Localization & ROI Cropping        |
   |    - Custom Indian License Plate YOLOv8s model      |
   |    - Aspect-ratio verification and margin expansion |
   |    - Quality crop caching to disk                   |
   +-----------------------------------------------------+
                       |
                       v
   +-----------------------------------------------------+
   | 4. Optical Character Recognition & Calibration      |
   |    - Modular OCR backends (EasyOCR / Fine-tuned CRNN / FastPlate ONNX Transformer)
   - Real-time Laplacian plate blur quantification (cv2.Laplacian variance)
   - Blur-aware confidence calibration scaling character probabilities with sqrt(sharpness/45.0)
   - CTC head output with top-3 character alternatives
   - Temperature scaling calibration (T = 0.5)
   +-----------------------------------------------------+
                       |
                       v
   +-----------------------------------------------------+
   | 5. Multi-Frame Evidential Consensus Fusion          |
   |    - Dynamic Frame Weighting:                       |
   |      w_i = (sharpness)^0.35 * (area)^0.25 * (conf)^0.40
   |    - Needleman-Wunsch string alignment with reduced |
   |      costs for optical confusion pairs              |
   |    - Indian vehicle plate grammar syntax prior:     |
   |      [AA][00][AA][0000]                             |
   |    - Calibrated posterior acceptance (P >= 0.50)    |
   |    - Margin over runner-up check (delta >= 0.12)    |
   |    - Preserves unreadable slots as '?'              |
   +-----------------------------------------------------+
            |                                   |
            v                                   v
   +--------------------+              +--------------------+
   | FusedPlate Object  |              | 6. Attribute Model |
   | E.g. "JH05AB?799"  |              | - Color K-Means    |
   | Per-slot vote log  |              | - Body Classifier  |
   +--------------------+              +--------------------+
            \                                   /
             \                                 /
              v                               v
   +-----------------------------------------------------+
   | 7. Registry Candidate Matching                      |
   |    - Matches against 500-vehicle SQLite registry    |
   |    - Length and state prefix pre-filtering          |
   |    - Positional plate scoring with confusable bonus |
   +-----------------------------------------------------+
                       |
                       v
   +-----------------------------------------------------+
   | 8. Original Multi-Criteria Ranking Engine           |
   |    Final Score = (0.65 * Plate_Score +              |
   |                   0.15 * Colour_Score +             |
   |                   0.12 * Body_Score +               |
   |                   0.08 * Visual_Score)              |
   |    - Matrix-based perceptual colour similarity      |
   |    - Body-type partial-credit compatibility         |
   |    - Generates Top-5 Shortlist with explanations    |
   +-----------------------------------------------------+
                       |
                       v
   +-----------------------------------------------------+
   | 9. Fail-Safe Abstention Engine                      |
   |    - 4-Way Abstention Checks:                       |
   |      1. Plate unreadability (> 70% '?')             |
   |      2. Top score < 0.52 (no_match_threshold)      |
   |      3. High-confidence character contradiction     |
   |      4. Score margin < 0.06 when plate has '?'      |
   |    - Emits NO_CONFIDENT_MATCH with plain-English    |
   |      investigative reason                           |
   +-----------------------------------------------------+
                       |
                       v
   +-----------------------------------------------------+
   | 10. Reporting, Dashboard & API Presentation         |
   |    - Print-ready A4 HTML and PDF reports            |
   |    - Forensic evidence frame crops & vote logs      |
   |    - Streamlit & Lightweight browser dashboards     |
   |    - Asynchronous FastAPI backend service           |
   +-----------------------------------------------------+
